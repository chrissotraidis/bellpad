# Status

Last updated: 2026-08-04

Current phase: native product hardening. Simulator/device compilation, input wiring, the top-right settings menu, render scaling, native GCI persistence, reproducible packaging, and original Apple-platform branding are established.

Near-term finish order is deliberately narrow: (1) prove a representative train/town scene through the mobile Metal path, (2) add user-facing GCI import/export and remove/reimport actions, (3) close the remaining disc-validation/release-audit gaps, and (4) run physical-device lifecycle, audio-route, memory, and signing checks when hardware is available. The SDL UIKit startup warning is tracked but is not allowed to displace functional work unless it produces a visible failure. Basic button wiring and gear-menu behavior are converged; broad activity-by-activity control replay is release acceptance, not ongoing implementation.
